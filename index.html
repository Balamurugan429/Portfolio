Flagship Research • 2025–2026

Explainable, Extraction-Aware Ensemble Learning for Groundwater Level Prediction

A hybrid machine learning architecture that forecasts dynamic groundwater depletion levels and categorizes regional criticality zones with post-hoc explainability.

Technical Report Peer Validation: In Progress

Architecture Overview & Methodology

Standard regression models struggle with dynamic groundwater levels due to non-linear seasonal recharge, uneven pumping schedules, and climatic shifts. This research addresses these limitations via an extraction-aware multi-model ensemble:

Regressors XGBoost (45%) + LightGBM (35%) + Random Forest (20%)
Explainability TreeExplainer with SHAP attribution and local LIME feature surrogates
Feature Pipeline Extraction-rate weighting, temporal lag vectors, rainfall recharge indexing
Classification Tier Zone Criticality Categorization (Safe, Semi-Critical, Critical, Over-Exploited)
Software Stack Python 3.11, Scikit-Learn, XGBoost, SHAP, Pandas, Matplotlib
Inspect Code & Pipeline on GitHub →
96.4% Cross-Validated R² Score

Achieved on testing hold-out partitions across regional monitoring wells.
